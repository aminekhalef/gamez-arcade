Jouer à la Chkobba en ligne

Retrouvez la Chkobba (aussi appelée Chkouba) dans votre navigateur. Jouez contre l’ordinateur en 11 ou 21 points, ou invitez quelqu’un à une table privée pour une partie à deux.

Ouvrir la table de Chkobba

Comment jouer à la Chkobba ?

  1. Choisissez une carte de votre main, puis les cartes à prendre sur la table. Les valeurs des cartes prises doivent correspondre à celle de votre carte jouée. À la table privée, les cartes de même valeur sont prioritaires.
  2. Videz la table pour marquer une Chkobba avant le dernier coup de la manche. Le sept de carreau, les carreaux et le nombre de cartes capturées comptent aussi dans le score.
  3. En ligne, il faut atteindre au moins 11 points et mener de deux points ou plus pour gagner.

Comment jouer avec quelqu’un ?

Créez une table privée et partagez le code à six caractères. L’autre personne saisit ce code sur la page du jeu, puis l’hôte lance la partie.

Combien de cartes contient le jeu ?

La Chkobba se joue avec 40 cartes. L’as vaut 1, la dame 8, le valet 9 et le roi 10.
