GAME GUIDE

Play RiddleGame online

RiddleGame is a single-player puzzle challenge with selectable difficulty levels. Solve each prompt, manage limited lives and build a scoring streak across a complete run.

How to play RiddleGame

  1. Choose a difficulty level before starting a run.
  2. Type an answer and submit it before moving to the next riddle.
  3. Correct answers increase the score and can build a streak.
  4. Incorrect answers cost a life unless relaxed mode is enabled.
  5. Finish the run with the highest score you can achieve.

Controls

  • Choose Easy, Medium, Hard or All Mixed, type an answer, and press the submit button or Enter.
  • Use Skip when needed; it reveals the answer and costs one life. Answers ignore spaces and punctuation.

Scoring and game format

Correct answers earn a base score plus a time bonus and a streak bonus, multiplied by difficulty. Relaxed mode removes the timer and time bonus; the best score is saved locally.

RiddleGame is single-player and runs entirely in the browser.

RiddleGame FAQ

What does relaxed mode change?
Relaxed mode removes the 60-second timer. You still have three lives and can build streaks, but there is no time bonus.
Does a wrong typed answer cost a life?
No. A wrong attempt can be retried. Skipping a riddle or running out of time costs one life.
