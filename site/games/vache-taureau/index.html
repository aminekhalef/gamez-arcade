GAME GUIDE

Play Vache Taureau online

Vache Taureau is a head-to-head number deduction game. Both players lock a secret four-digit code, then exchange guesses and use exact and misplaced matches to solve the rival code first.

How to play Vache Taureau

  1. Choose a four-digit secret with no repeated digits and lock it before the match begins.
  2. Submit a four-digit guess when it is your turn.
  3. A taureau is a correct digit in the correct position; a vache is a correct digit in a different position.
  4. Use the private table log to compare previous guesses and clues.
  5. The first player to identify all four digits in their correct positions wins.

Controls

  • Lock a four-digit secret containing four different digits before the host starts the match.
  • On your turn, enter four different digits and submit the guess; the shared table log keeps every clue visible.

Scoring and game format

A Taureau marks a correct digit in the correct position and a Vache marks a correct digit in the wrong position. Four Taureaux win immediately.

Vache Taureau is an online two-player game played in a private six-character room.

Vache Taureau FAQ

Can a secret or guess repeat a digit?
No. The game requires four different digits in both secrets and guesses.
Does the table log survive a reconnect?
Yes. The server stores a separate capped history for each room and restores it when a player reconnects.
